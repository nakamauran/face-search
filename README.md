# 顔類似検索（face-search）

数千枚の顔写真から、探したい顔に似ている顔を探すツールです。集合写真のように複数人写っている写真も対象で、1枚から全員の顔を検出します。

ローカル専用です。写真を外部にアップロードしません。

現在のバージョン: v0.7.0（2026-11-19）

## 特徴

- 検出: InsightFace `buffalo_l`（SCRFD）
- 特徴量: ArcFace 512次元、コサイン類似度で検索（NumPy 総当たり）
- 集合写真対応: 1枚から全員の顔を検出し、ヒット顔はオレンジ枠、他の顔はグレー枠で表示。「5人中 3番目」のように写真内の位置も表示
- インデックス作成: 写真フォルダを再帰走査し、`index.npz` に保存。2回目以降は差分更新（変わっていない写真は再利用）
- 並列処理: 1〜8ワーカーでインデックス作成を高速化
- コピー保存: 検索結果にチェックを入れて別フォルダへコピー。元ファイルは残り、同名ファイルは連番（`photo_1.jpg`）になる
- GUI: tkinter のみ。日本語表示

## 動作環境

- OS: Windows 10 / 11（exe 版・Python 版とも）
- Python: 3.10〜3.14（推奨は 3.13。3.15 は未対応）
- GPU（任意）: DirectX 12 対応 GPU（DirectML 用）または NVIDIA 製 GPU（CUDA 用）
- ディスク: 初回モデルダウンロードに 500MB 以上の空き容量が必要

Python 3.15 は未対応です。onnxruntime と scikit-image に 3.15 用の wheel がないため、依存パッケージをインストールできません。

## クイックスタート

### exe 版（Python が入っていない PC でも使える）

exe を作る作業自体は Windows の PC で行う必要があります。Linux で作ったバイナリは Windows では動きません。

1. このリポジトリを Windows の PC にコピーします。
2. `build_exe.bat` をダブルクリックします（既定は DirectML 版）。
3. 仮想環境の作成（`.venv-build`）→ 依存パッケージのインストール → PyInstaller のビルドが自動で進みます。数分〜10分程度かかります。
4. `dist\face-search\face-search.exe` ができます。**exe だけをコピーしても動きません。`dist\face-search` フォルダごとコピーしてください。**

```cmd
build_exe.bat            :: DirectML 版（既定・推奨）
build_exe.bat directml   :: DirectML 版
build_exe.bat cuda       :: CUDA 版（NVIDIA 専用）
build_exe.bat cpu        :: CPU 版
```

PowerShell 版（`.\build_exe.ps1 [-Provider cpu|cuda|directml]`）もあります。実行ポリシーで止まる場合は、管理者で `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` を実行してください。

初回起動時に InsightFace のモデル `buffalo_l`（約281MB）を `C:\Users\<ユーザー名>\.insightface` へダウンロードします。ネットワークが必要で、数分かかります。2回目以降はダウンロードされません。

### Python 版

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

GPU で動かしたい場合は、`requirements.txt` の代わりに `requirements-gpu-directml.txt`（DirectML）または `requirements-gpu-cuda.txt`（CUDA）を使ってください。onnxruntime / onnxruntime-gpu / onnxruntime-directml は同居できないため、切り替えるときは新しい venv を作るか、古い方をアンインストールしてください。

## 使い方

1. 左で写真フォルダを選び「インデックス作成」を押します。フォルダ内に `index.npz` が作られます。次回からは「開く」で読み込めます。サブフォルダも再帰的に読み込みます（隠しフォルダは対象外）。
2. 中央でクエリ画像を選びます。複数人写っていたら、探す顔をコンボボックスで選びます。クエリも集合写真でかまいません。
3. しきい値（既定 0.50）と表示件数（既定 20件）を調整して「検索」を押します。
4. 結果をクリックすると右に拡大表示されます。ヒット顔はオレンジ枠、他の顔はグレー枠です。
5. コピーしたい結果にチェックを入れ、保存先フォルダを選んで「チェックしたものをコピー」または「ヒット全件コピー」を押します。元ファイルは残ります。

左パネルの設定：

- 検出サイズ（640 / 1024 / 1280、既定 640）: 検出時の入力サイズ。1280 は小さい顔も拾うが遅い。集合写真は 1280 がおすすめ。
- 並列数（1〜8、既定 4）: 同時に処理するワーカーの数。ワーカー1つあたりモデル読み込みでメモリを約1GB使うため、メモリ 8GB 未満の PC では 2 以下にしてください。GPU を使う場合は 1〜2 がおすすめ。
- インデックスを作り直す: オフ（既定）は差分更新。オンにすると全ての写真を処理し直します。

コマンドラインでインデックスだけ作ることもできます。

```powershell
python indexer.py C:\Users\<ユーザー名>\Pictures -o index.npz
python indexer.py C:\Users\<ユーザー名>\Pictures --min-size 20 --min-score 0.5 --det-size 1280
python indexer.py C:\Users\<ユーザー名>\Pictures --workers 4 --rebuild
```

## しきい値の目安

ArcFace のコサイン類似度は、同一人物で 0.5〜0.7 程度、他人で 0.3 前後になることが多いです。

- 漏れが多い（本人が出てこない）→ しきい値を下げる（0.40 など）
- 誤検出が多い（他人が混ざる）→ しきい値を上げる（0.60 など）

集合写真では顔が小さいため、しきい値は 0.40〜0.45 から試すのも手です。写真の写り（角度・照明・年齢・画質）で最適値は変わるため、0.50 から試して調整してください。

## 集合写真について

集合写真では顔が約20pxと小さいことが多く、最小顔サイズの既定を 20px にしています。50px 除外だと集合写真の顔がほぼ全て捨てられてしまいます。さらに小さい顔も拾いたい場合は、コマンドラインの `--min-size 16` を使います。

検出サイズ 1280 の方が小さい顔も拾えますが、1枚あたりの検出は約1.5倍遅くなります。数千枚ある場合は 640 でまず試し、漏れが多い写真だけ 1280 で作り直すのも手です。

## GPU を使う

`onnxruntime` / `onnxruntime-gpu` / `onnxruntime-directml` は同じパッケージを置き換え合う関係で、1つの環境・1つの exe には1種類しか入りません。使うデバイスはビルド時に1つ選びます。実行時に切り替えることはできません。

| デバイス | 対象 | 備考 |
|---|---|---|
| DirectML（AMD・Intel・NVIDIA共通） | DirectX 12 対応 GPU | 推奨。既定。AMD・Intel・NVIDIA のどれでも動く |
| CUDA（NVIDIA） | NVIDIA 製 GPU | 明示指定でのみ選べる。ドライバ 621.x 環境では動かない既知の問題あり（下記） |
| CPU | 全ての PC | 追加のインストールは不要 |

### DirectML（推奨）

```cmd
build_exe.bat directml
```

Windows 標準の DirectML を使うため、追加の DLL は要りません。Python 版は `requirements-gpu-directml.txt` を使います。

### CUDA（明示指定のみ）

```cmd
build_exe.bat cuda
```

`onnxruntime-gpu[cuda,cudnn]` を使います。`[cuda,cudnn]` が無いと nvidia-* パッケージ（CUDA / cuDNN の実行時ライブラリ）が入らず、CUDAExecutionProvider が一覧に出ません。CUDA Toolkit の別途インストールは不要な場合が多いです（実行時ライブラリは nvidia-* パッケージとして一緒に入ります）。CUDA 13 ビルド（onnxruntime-gpu 1.27 以降）を使うため、NVIDIA ドライバは CUDA 13 対応（R580 以上）にしておいてください。

**既知の問題：ドライバ 621.x の環境では CUDA 版が動きません。** onnxruntime-gpu 1.26.0（CUDA 12.8）でも 1.32.0（CUDA 13）でも、プロバイダ DLL の読み込み時に DllMain 失敗（WinError 1114）で CUDAExecutionProvider が一覧に出ず、CPU になります。原因はドライバ 621.x 側の CUDA 初期化の問題が最有力で、アプリ側の修正では直らない見込みです。CUDA が動かない場合は DirectML 版を使ってください。

### 実行時のデバイス確認

起動時に「利用可能なプロバイダ: [...]」と「推論デバイス: ...」が `face-search.log` に出ます。ビルド時に選んだデバイスが実行時に使えない場合は、警告をログとステータスバーに出して CPU に切り替わります。ダイアログで落ちることはありません。

差分更新で処理する写真が1枚も無い（全て再利用）場合、推論が走っていないため、集計ログと完了ダイアログの「デバイス」欄は「処理なし（全て再利用）のため未使用（検出されたデバイス: ...）」と出ます。「GPU が使われていない」という意味ではなく「使う処理が無かった」という意味です。

## ログ（face-search.log）

起動・インデックス作成・検索・エラー発生時の例外全文（traceback）を、日時付きで `face-search.log` に書き込みます。

- Python 版：プロジェクトフォルダの `face-search.log`
- exe 版：exe と同じフォルダの `face-search.log`（`dist\face-search\face-search.log`）
- exe のあるフォルダに書けない場合（`C:\Program Files` など）：一時フォルダ（`%TEMP%\face-search.log`）へ自動で切り替わります。

exe 版はコンソールが出ないため、ログファイルが唯一の手がかりです。GUI の左パネルに「ログを開く」ボタンがあります。エラーが出たら、まずこのログファイルを確認してください。

### 診断ツール（diagnose.py）

環境・モデル・フォルダ・画像読み込みを調べます。結果は画面と `face-search.log` の両方に出ます。

```powershell
python diagnose.py C:\Users\<ユーザー名>\Pictures
python diagnose.py C:\Users\<ユーザー名>\Pictures C:\path\to\query.jpg --detect-first
```

`--detect-first` を付けると、最初の1枚で実際に顔検出を走らせ、検出数・顔サイズ・最小顔サイズ 20 / 50 で残る件数を表示します（集合写真の確認用。数十秒かかります）。

## トラブルシュート

### exe が起動しない・何も起きない

- `dist\face-search` フォルダごとコピーしたか確認してください。exe だけをコピーしても動きません。
- 初回はモデルのダウンロードで数分かかるため、しばらく待ってください。
- ウイルス対策ソフトに隔離されていないか確認してください。PyInstaller 製の exe は誤検出されることがあります。
- exe を `C:\Program Files` など書き込み制限のある場所に置いている場合、デスクトップやドキュメントなど書き込み可能な場所へフォルダごと移してください。

### 「インデックス作成に失敗しました」と出る

まず `face-search.log` を確認してください。ログの末尾に例外の全文（traceback）が残っています。よくある原因：

- 初回のモデルダウンロード失敗：初回は約281MBを `C:\Users\<ユーザー名>\.insightface` へダウンロードします。ネットワーク接続と空き容量（500MB以上）を確認してください。モデルフォルダが無い・途中で止まっている場合は、`.insightface` フォルダを削除してからもう一度試すとダウンロードし直します。
- `dist` フォルダごとコピーしていない：exe だけをコピーすると onnxruntime の DLL が無くて動きません。
- ウイルス対策ソフトの隔離、exe の置き場所の書き込み権限（上記参照）。

### GPU を選んだのに CPU で実行される

ログの「利用可能なプロバイダ: [...]」と「推論デバイス: ...」を確認してください。

- 「CUDAが使えないためCPUで実行します」「DirectMLが使えないためCPUで実行します」と出ている場合：ビルド時に選んだデバイスが実行時に使えていません。ドライバの確認か、別のプロバイダでのビルドし直しを検討してください。使うデバイスはビルド時に決まるため、実行時に切り替えることはできません。
- 警告も出ず「利用可能なプロバイダ: ['CPUExecutionProvider']」しか出ない場合：GPU の実行時 DLL が同梱されていません。CUDA 版は `onnxruntime-gpu[cuda,cudnn]` でビルドし直してください。ドライバ 621.x 環境では CUDA 版自体が動かない既知の問題があるため、その場合は DirectML 版を使ってください。

### 顔が検出されない

顔が 20px 未満で小さい、横顔・後ろ向き、ブレている、暗すぎる場合は検出されないか除外されます。`--min-size` を下げる（16 など）か、GUI の「検出サイズ」を 1280 にすると拾える場合がありますが、精度は下がり、処理も遅くなります。

### 検索結果に他人が混ざる

しきい値を上げてください。兄弟・親子など顔立ちが似ている人は区別が難しい場合があります。

### `index.npz` が見つからない / 開けない

インデックス内のパスは絶対パスで保存されているため、写真フォルダを移動すると検索結果の画像が読めなくなります。その場合はインデックスを作り直してください。

### `insightface` のインストールで失敗する

Visual C++ のビルドツールが必要な場合があります。`pip install insightface` が失敗する場合は、まず `pip install onnxruntime opencv-python-headless numpy Pillow` が入るか確認し、InsightFace だけ後から入れ直してください。

## 既知の制限

- 横顔・斜め顔・小さい顔・マスク着用時の精度は正面顔より落ちます。
- 同じ人物でも年齢・髪型・照明が大きく違うと類似度が下がります。
- 顔立ちが似ている他人（兄弟・親子など）が誤って上位に入ることがあります。
- インデックスは絶対パスで保存するため、写真フォルダを移動したら作り直しが必要です。
- CPU 実行では、数千枚のインデックス作成に時間がかかります。並列数・GPU・差分更新で短縮できます。
- exe 版はビルド時に選んだプロバイダ（CPU / CUDA / DirectML）で固定されます。デバイスを変えたい場合はビルドし直してください。

## 利用上の注意

本ソフトウェアは顔画像から特徴量を抽出し、類似する顔を検索します。顔の特徴量は日本の個人情報保護法でいう個人識別符号に当たり、その取り扱いには本人の同意をはじめとする法令上の配慮が必要です。

- 自分が撮影した写真、または利用する権利が確認できる写真にのみ使用してください。
- 本人の同意なく第三者の顔を収集・識別・追跡する目的では使用しないでください。
- 監視、プロファイリング、本人に不利益を与えうる判断への利用は想定していません。
- 検出・照合の結果は常に正しいとは限りません。他人を同一人物と判定する誤りが起こりうることを前提に扱ってください。
