# 顔類似検索プロトタイプの GPU（DirectML）版 依存パッケージ。
#
# DirectX 12 対応 GPU（AMD・Intel・NVIDIA 共通）で動かす場合に
# requirements.txt の代わりに使う。
# onnxruntime / onnxruntime-gpu / onnxruntime-directml は同居できない
# （同じ onnxruntime を提供するため競合する）。切り替えるときは
# `pip uninstall -y onnxruntime onnxruntime-gpu` で古い方を消すか、
# 新しい venv を作ること。
#
# 対応 Python: 3.10〜3.14（主対象は 3.13.17。3.15 は未対応）。
# 下限バージョンの根拠は PyPI の cp313 / cp314 wheel の有無
# （2026-11-17 確認。最新: onnxruntime-directml 1.24.4）。
# Windows 専用。DirectX 12 対応 GPU とドライバが必要。
# CUDA より遅いことが多いが、NVIDIA 以外の GPU でも動く。
#
# 使い方（Python 版）:
#   py -3.13 -m venv .venv-gpu
#   .\.venv-gpu\Scripts\Activate.ps1
#   pip install -r requirements-gpu-directml.txt
#   python app.py
# exe 版で使う場合は build_exe.bat directml でビルドすること。

# py3-none-any wheel のため Python バージョンに依存しない。
insightface>=2.1
# cp313 wheel は 1.20.0〜、cp314 wheel は 1.24.1〜。
# 3.13 以上は 1.24.1 以上が必要（1.24.1 以降に cp310 wheel がないため分離）。
onnxruntime-directml>=1.24.1; python_version >= "3.13"
onnxruntime-directml>=1.20.0; python_version < "3.13"
# cp37-abi3 wheel のため 3.10〜3.15 で同じ wheel が使える。
opencv-python-headless>=4.10.0.84
# cp313 wheel は 2.1.0〜、cp314 wheel は 2.3.2〜（2.3.2 以降に cp310 wheel がない）。
numpy>=2.3.2; python_version >= "3.13"
numpy>=2.1.0; python_version < "3.13"
# cp313 wheel は 10.4.0〜、cp314 wheel は 11.3.0〜。
Pillow>=11.3.0
